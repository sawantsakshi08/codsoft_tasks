 Task 3: Data Visualization Dashboard

 Project Overview
This project analyzes sales data using Python, Pandas, and Matplotlib. It creates visualizations to understand sales performance across regions, categories, and months.

 Objectives
- Analyze sales by region and category.
- Visualize monthly sales trends.
- Understand category contribution and sales distribution.
- Generate summary CSV files and charts.

 Technologies Used
- Python
- Pandas
- Matplotlib

 Project Structure
- `create_dashboard.py` — Python script to generate charts and summaries.
- `data/sales_dashboard_data.csv` — Sales dataset.
- `charts/` — Generated visualization images.
- `output/` — Summary CSV files.
- `Task3_Data_Visualization_Report.pdf` — Project report.
- `requirements.txt` — Required Python libraries.

 How to Run

1. Install Python.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Run the script:

   `python create_dashboard.py`

 Key Findings
- Total sales: ₹51,00,000
- Top-performing region: North
- Top-performing category: Electronics
