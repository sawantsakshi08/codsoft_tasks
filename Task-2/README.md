 Exploratory Data Analysis (EDA) of Retail Sales

 Objective
Explore a sample retail sales dataset to identify trends, patterns, relationships, and potential outliers.

 Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

 Tasks Performed
- Calculated revenue using quantity and unit price.
- Analyzed revenue by region and product category.
- Examined monthly revenue trends.
- Visualized revenue distributions and relationships.
- Identified potential outliers using the IQR method.

 Files Included
- `Task2_Exploratory_Data_Analysis.ipynb` — Analysis notebook
- `analyze_sales.py` — Python analysis script
- `EDA_Report.md` — Findings and recommendations
- `data/sales_data.csv` — Input dataset

 Key Findings
- Highest-revenue region: North — ₹684,200.
- Highest-revenue category: Electronics — ₹1,809,000.
- Two potentially unusual records were identified.

 Learning Outcomes
Practiced exploratory data analysis, data visualization, descriptive statistics, and outlier detection.
